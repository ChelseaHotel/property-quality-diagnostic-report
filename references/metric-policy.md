# 指标口径

## 实际问题

- `problem-or-score`：问题文本有效，或扣分大于 0。
- `problem-only`：仅问题文本有效时计入。
- `score-only`：仅扣分大于 0 时计入。
- `status-based`：状态不属于已整改或无问题状态时计入；仅在源系统明确以状态定义问题时使用。

问题文本有效指：去除空白后不为空，且不在 `no_issue_values` 中。

## 整改状态

将源状态映射为：

- `done`：已整改、已完成、已关闭、完成。
- `pending`：待整改、整改中、未完成、处理中、待处理。
- `unknown`：其他状态。生成前要求人工确认或通过配置补充。

## 核心指标

- 检查记录：筛选后全部记录。
- 实际问题：符合问题口径的记录。
- 已整改：实际问题中状态为 `done`。
- 待整改：实际问题中状态为 `pending`。
- 整改率：已整改 ÷ 实际问题。
- 问题扣分：实际问题扣分合计。
- 待整改扣分：待整改问题扣分合计。

零分问题仍可成为实际问题和待整改问题，不得因扣分为零而删除。

## 动态管理结论

从数据计算，不在模板中硬编码：

1. 整改率最低板块。
2. 待整改数量最多板块。
3. 未整改扣分最高板块。
4. 单条扣分最高的未整改问题。
5. 整改率低于 70% 的风险板块。
